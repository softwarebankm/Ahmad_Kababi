# کافه رستوران احمد کبابی - وب‌سایت منوی دیجیتال

منوی فارسی واکنش‌گرا با جستجوی آنی و دسته‌بندی آیتم‌ها.

## ویژگی‌ها
- منوی دیجیتال برای کافه رستوران احمد کبابی
- جستجوی غذاها و نوشیدنی‌ها
- تب‌های دسته‌بندی
- داده‌های متنی قابل ویرایش در `data/`
- اجرای مستقیم با وب‌سرور استاتیک (برای fetch فایل‌های متنی، فایل را مستقیم از مرورگر باز نکنید)
